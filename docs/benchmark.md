# Замер моделей: токены, скорость, стоимость

Замеры сделаны 8 ноября 2026 на MacBook Pro M5 Pro, 48 ГБ, через Ollama 0.40.15.

## Токены и скорость одной оценки

| Модель | Режим | Вход, токенов | Выход, токенов | Время на чат | Время на звонок |
|---|---|---|---|---|---|
| Gemma 4 31B | с размышлением, JSON | ~2 200 | ~1 800 | ~52 с | ~100 с |
| Qwen 3.6 35B-A3B | быстрый, строгая схема | ~2 300* | ~900–1 800 | ~15 с | — |

\* У Qwen в половине случаев был повторный запрос (не указал реплику-доказательство), поэтому средний вход ~4 000.

Gemma: 65 диалогов DEV, 0 ошибок формата, 0 повторных запросов. Звонки длиннее чатов в ~1,9 раза по токенам.

## Репетиция контрольного часа

10 чатов DEV (RU/KZ/EN) через Gemma 4 с финальным промптом: **9,2 минуты**, 0 ошибок формата,
0 повторных запросов, у всех 80 критериев есть ссылка на реплику, проверка формата JSON 1.0 пройдена.
Скачивание набора через API организаторов — 2,6 секунды.

## Качество

- Gemma 4 нашла все подставные грубые нарушения в DEV (перевод денег лично, личный номер за плату) на RU, KZ и EN.
- Qwen 3.6 совпадает с Gemma в 79% ответов (76 из 96 на 12 диалогах); расхождения — в спорных критериях: эмпатия, завершение, ведение диалога.
- Средний балл по языкам у Gemma ровный: RU 85.3, KZ 89.4, EN 85.8 — казахский не проседает.

## Вывод

- **Gemma 4 31B** — основная модель: точнее на спорных критериях, данные не покидают контур компании, $0 за оценку.
- **Qwen 3.6** — быстрый режим (в 3–4 раза быстрее) для массовой предварительной проверки.
- Узкое место локального варианта — пропускная способность, а не деньги: на одном ноутбуке ~1 700 чатов в сутки (Gemma) или ~5 800 (Qwen). Для банка это решается одним GPU-сервером, который окупается против API за 1–2 месяца при 100 000 чатов.
