# CQA — Conversation Quality Analytics

Прототип для хакатона Freedom Broker / Data Challenge: автоматическая оценка работы оператора
в чатах и звонках (RU / KZ / EN) по настраиваемому чек-листу, с обоснованиями, ссылками на реплики,
апелляцией и пересмотром оценки.

> 🚧 В разработке. Инструкции по запуску появятся здесь.

## Структура
- `data/` — наборы диалогов (`dev.json` — DEV-набор, 65 диалогов)
- `results/dev/results.json` — результаты по DEV-набору
- `results/prod/results.json` — результаты по контрольному набору
